# Security policy

Do not upload account numbers, government identifiers, secrets or private customer data to the demo instance. File uploads are validated by size, filename, MIME and content signature; parsers must treat source text as untrusted data. The Agent profile is disabled by default and cannot send messages, write external CRM records, promise refunds or decide legal liability.

Please report security issues privately to the repository maintainer rather than opening a public issue with sensitive details.
